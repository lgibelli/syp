# SYP — Sync Your Playlists

A browser extension to export, import and copy playlists between **Spotify**, **YouTube Music**, **Apple Music** and **Amazon Music**, working directly inside the web players you're already logged into.

- No developer API keys and no account to create
- No servers: your playlists and sessions never leave your browser
- Portable JSON export/import, so you keep a backup you own

> **Status:** early planning. There is no usable code yet.
